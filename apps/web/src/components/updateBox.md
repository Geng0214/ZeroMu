### 本机配音与背景移除

- Windows 可使用设备已安装的系统音色生成配音，无需配置云渠道密钥，支持 MP3、WAV。
- 本机背景移除可在生图工作站或镜头图片编辑器使用。先配置 FFmpeg，再下载并启用约 224 MB 的 BiRefNet 模型；图片在本机处理，输出原尺寸透明 PNG。复杂边缘请预览后再采用。
- 镜头背景移除保存为新候选，保留原图、来源版本和任务；当前采用仍由你选择。蒙版局部重绘与扩图尚未提供。

### 制作与复用

- 画布仓库可直接打开已有项目。制作模板的文字可独立编辑；旧模板会保留固定参考并建立编辑副本，遇到不同内容的已有副本时提示冲突并保留两份文件。
- 图片、视频和音频工作站的草稿与参考文件随项目保存，重开应用或移动项目后可恢复；未选项目的草稿保存在应用数据中。当前网页来源的旧缓存可迁移，其他历史端口的缓存仍需从原来源取回。
- 草稿读取失败时保留原文件并提供重试；多个窗口同时编辑时提示冲突，避免静默覆盖。完整项目包包含已保存的草稿和参考文件。
- 离开工作站或刷新后，继续使用上次选择的草稿保存目录；明确打开其他项目时同步工作站目录。未完成任务显示状态、创建时间及原错误，可直接查看对应任务。
- 分镜支持拖动把手、方向键和上下移按钮排序，显示插入位置并支持列表边缘滚动；重排保留镜头身份、参考、候选和采用关系。
- 定位镜头时收起制作面板，让对应画布节点完整可见。
- 角色、场景和道具可保留固定版本；更新所选镜头参考时，可查看历史依据与受影响范围。
- 全局素材可独立带入项目，已有素材可新增版本；缺失原件可按摘要核对后补回。
- 个人提示词与制作模板支持编辑收藏、变量、输入映射、审阅导入导出和独立项目应用。
- 项目重命名会同步更改项目文件夹名称和项目记录。
- 工作空间支持永久删除项目文件夹，删除前显示项目路径并要求确认。
- 新建项目默认按“我的项目1”“我的项目2”依次命名，项目名称保存在项目记录中。
- 项目文件夹直接保存在工作空间下，每个项目可包含“无限画布1”“无限画布2”等多张画布。
- 画布自动按所属项目分类，支持查看全部画布或按项目筛选；画布卡片和编辑器显示所属项目，管理模式支持多选与批量删除。

### 预览与编辑

- 修正公式预览中的字体、分数和上下标；公式和图表使用应用内资源。
- 工具配置校验增加超时与异常保护；校验失败时保留原配置和禁用状态。
- 工具运行增加取消与异常退出保护。调用结束时释放等待和临时引用，已开始的文件写入完成后再返回结果。
- 兼容工具扩展的自定义参数预处理和显示钩子；运行超时或异常时会明确提示。
- 图片和视频使用本机缩略图；查看原图、下载及明确播放时读取原件。视频离开视口后释放播放器，再次播放保留进度。
- 视频节点的音量浮层和截帧菜单在使用时创建，减少大画布中的隐藏元素；播放、音量和截帧操作继续保留。
- 音频点击前不预读正文，原生音视频控件可使用键盘操作。
- 镜头图片支持本地裁剪、旋转和尺寸调整，保存为新的版本和候选，保留原图及修改依据。
- 已采用片段可排序、裁切、配置声音和字幕，并导出 MP4、字幕及素材索引；完整项目可打包和恢复。
