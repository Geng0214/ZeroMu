# 媒体生成

让 Agent 查询已配置的媒体模型，按要求生成图片、视频或音频，并将结果保存到当前工作区。

## 使用方式

先在媒体渠道配置中添加供应商，配置其 API Key 和需要使用的模型，再打开项目。
需要 Agent 直接生成文件时，可以说：“请直接生成一张暖色调产品海报，保存到工作区。”
需要在节点内制作时，配合“画布操作”工具，让 Agent 使用对应节点的生成功能。

## 支持的功能

- 查询当前允许使用的图片、视频和音频模型，以及模型支持的生成选项。
- 选定视频模型后核对对应制作规则：明确的 Seedance 2.0/2.5 保留专项，其他视频模型使用独立通用分支。
- 根据提示词生成图片，可按模型能力使用参考图、画幅和尺寸。
- 生成视频，可按模型能力使用图片、视频、音频、首尾帧，以及时长、分辨率和声音选项。
- 生成音频，可按模型能力使用参考音频、音色、语速、音量和输出格式。
- 等待生成并保存后返回文件位置；默认保存在工作区的 `assets/generated`，也可指定工作区内的输出目录。

参考素材须已存在于工作区。具体可用功能取决于所选模型，并非所有模型都支持全部选项。

## 视频制作规则

Agent 先查询实际模型，本轮提供 `resolveVideoWorkflow` 时用它核对所选渠道和模型、当前能力及规则资料位置。此工具只读，不发起生成或改变采用。资料从实际安装的 workflow 技能读取，未安装时说明缺项；模型被移除或视频权限关闭时不会偷偷替换默认模型。该工具随直接视频权限提供；使用独立节点时仍按节点现场配置和 workflow 分流，不要求开启直接生成权限。

显示名称中的“2.5”不等于 Seedance 2.5，渠道别名不能仅凭标签套用专项。实际时长、分辨率、参考和声音始终以该渠道能力为准，专项提示词规则不表示厂商一定支持相同参数。用户换模型后重新核对规则、输入和费用范围，原任务、候选及采用保留。

## 配置

在“设置 → 插件市场 → 已安装”找到“媒体生成”，点击“配置”。
“允许 AI 生成图片”“允许 AI 生成视频”“允许 AI 生成音频”默认全部开启，分别控制 Agent 可直接调用的生成类型。
供应商密钥在媒体渠道中单独配置，不复用文本模型密钥；这里的开关不代替节点自身的配置。
