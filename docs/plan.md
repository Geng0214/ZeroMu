## 产品目标

把零幕做成面向个人创作者与小型工作室的 Windows 本地 AI 影像与漫剧工作台，让用户连续完成：

**灵感与草稿 → 剧本 → 角色与场景 → 分镜 → 导演机位与参考 → 生成任务 → 编辑与候选采用 → 成片 → 项目交付与复用。**

项目掌握在用户手中；模型由用户选择；生成、修改与费用有据可查；关闭应用、切换项目、更新版本或迁移文件后能够继续制作。

产品提供两条相通的路径：图片、视频、音频的快速创作，以及有分镜、版本和采用关系的完整制作。快速创作的结果能够进入正式项目，复杂设置不成为第一次使用的前提。

## 本次修订原则

- 保留原 F01–F12、M0–M5 和 P2 全量目标，不把未完成的真实制作、费用或发行验证移除。
- 增加 F13–F18：首用与草稿、远程提示词来源、外部工作流、导演场景资产、手动动画编辑、镜头参数复用。
- “已有但待验收”安排验证和缺陷修复；“确实缺少”才安排新开发。已有分镜、版本、候选、成片、模板和插件系统均继续复用。
- 原范围完成可作为稳定阶段版；新增本地扩充范围也完成后，才称为本次丰富化计划整体完成。云同步等候选方向单独列项。
- 延续当前阶段约束：原生观感、文件选择器和人工交互试用由用户最终验收。本次规划不改变这一安排，不新增付费授权。
- 当前工作区存在未提交改动，本次保留它们。旧对比中的 ZeroOne 路径只是历史位置，当前判断以本目录源码为准。

- 每次只推进明确要求的阶段；本轮在 R0 修复、必要验证与记录同步后停止，R1 等待用户明确指令。
