# 设计与交互约定

更新：2026-10-23。合并首页、工作站与导演台约定，解决旧设计记录中布局阶段不同造成的冲突；具体状态以 [progress](progress.md) 为准。

## 产品与导航

| 位置 | 主要职责 |
| --- | --- |
| 首页 | 继续最近创作、新建画布、进入图片/视频/音频创作、打开项目 |
| 画布仓库 | 查找已有项目与画布；打开目录、导入画布、新建画布各有明确含义 |
| 工作站 | 提示词、参考、模型实际能力、生成结果与历史；可发送到已有画布或镜头 |
| 项目工作区 | 画布/分镜为同一内容的视图；素材、Agent、导演台与成片为相关面板/编辑器 |
| 任务中心 | 进行中与异常数量、固定生成依据、原任务恢复与原位置定位 |
| 全局资料库 | 素材、个人提示词与制作模板；带入项目时明确创建独立对象 |
| 设置 | 界面、画布、模型配置、创作偏好与关于；实现细节不散落到普通创作流程 |

主菜单负责回到主页与仓库；画布名称下拉仅切换当前项目画布，旁边加号新建画布。保存状态持续可见，失败有重试。镜头定位应让目标完整可见，避免制作面板或底栏遮挡。

## 关键页面

- **工作站**：图片、视频、音频沿用左侧创作栏和右侧结果区；分界可拖动/键盘调整。旧记录中的底部/侧边切换是历史设计，不恢复为当前要求。
- **导演台**：沿用场景列表、中央视口、属性三栏；先布景再设置机位，名称可读、排序把手独立。焦距可输入，截图到画布明显可见；无可用动画时收起不可用的播放/视频导出。
- **分镜**：剧情、时长、参考与采用可比较；支持拖动、按钮及键盘排序，保留镜头身份与引用。生成与采用分开。
- **成片**：剪辑顺序、入出点与声音设置可见；保存后保留键盘焦点；预览与导出使用同一编辑清单。
- **工具卡片**：独立页面继承语言、主题与字号；提问选项、自由补充、提交/跳过和错误完整可读，节点定位回到正确画布。

## 视觉

延续深炭灰、薄荷色与克制的层级；同时维护浅色。品牌素材色与页面主题 token 分开：品牌墨青 `#12343B` / 薄荷绿 `#29D7B0` 不强行替换页面实际主题。

| 用途 | 既有参考 |
| --- | --- |
| 首页 | 背景 `#101111`、面板 `#202120`、正文 `#f1f1ec`、强调 `#b6dec9` |
| 工作站暗色 | 背景 `#0b0b0b`、面板 `#171717`、字段 `#0c0c0c`、正文 `#f0efed`、强调 `#c6e4d5` |
| 日间模式 | 背景 `#e8e8e4`、面板 `#f1f1ed`、浮层 `#f6f6f2`、正文 `#2c302d`、辅助文字 `#60675f`；沿用原有强调色 |

沿用应用字体与现有主题变量，不按文档复制一套新 token。标题突出当前动作，辅助信息减少抢占；明度与细边框区分层级，圆角和控件密度延续已有组件。

日间模式的灰白底色集中在 `apps/web/src/assets/lightTheme.scss`，首页、工作站、资料库、Element Plus 与 TDesign 共享，减少大面积纯白。文字保持清晰对比，不对整个页面或素材图片添加亮度滤镜；深色模式沿用既有配色。

## 交互与可访问性

- 主要按钮有明确文字；图标按钮有可访问名称和可见键盘焦点。
- 保存目录、目标项目、生成范围和费用条件在需要决策的位置说明；未配模型时保留输入并提供配置入口。
- 上传参考先确认类型和顺序；切换模型重新校验能力，不把预期时长当作模型保证。
- 确认影响范围后再更新素材或镜头；导出/导入可审阅，不自动覆盖原项目。
- 区分空列表、无搜索结果、加载、失败、恢复中及待核对；错误使用可理解文案并保留原输入。
- 长内容在所属区域滚动，底部生成/保存操作保留可达性；窄窗口与大字号防止遮挡和横向溢出。
- 动效尊重减少动态偏好；不支持特效时平稳回退。3D 编辑复用渲染资源，缩略图与媒体按需更新。

标准窗口、应用字号、深浅主题与系统 DPI 按 [验收矩阵](acceptance.md#设备与规模) 分别验证；浏览器断点和一次截图不能证明所有原生设备均通过。

历史细节、截图与性能采样：[首页](archive/homeDesign.md)、[工作站](archive/studioDesign.md)、[导演台](archive/directorStagePlan.md)、[交互与凭据](archive/directorAndApiPlan.md)、[成片键盘](archive/filmKeyboardAndLayout.md)。历史中的布局和已完成范围不自动覆盖本页约定。

## 桌面图标与启动画面

2026-10-24：桌面使用浅灰白圆角底与黑色 Z，保留透明圆角；ICO 包含 16、20、24、32、40、48、64、96、128、256 像素。网页原有透明 PNG 保留，桌面源稿为 `packages/assets/zeromuApp.svg`，启动字标为 `zeromuLogo.svg`；字形已转轮廓，运行时不依赖系统字体。

启动画面使用透明外沿、近白圆角卡片与黑色字标：400ms 入场仅播一次，等待阶段使用三个灰色呼吸圆点，没有进度横条。页面就绪后先收起圆点，再淡出字标与卡片，完整播放 300ms 退场后才显示主窗口。极快启动保留完整入场后退出；应用原有关闭启动动画的设置继续有效。Windows 的 400×160 逻辑尺寸和 DPI 渲染方式保持。

在 Windows 手动执行 `bun packages/startup/scripts/buildBrand.ts`，从 SVG 导出桌面 ICO、Mac iconset 与五层 Lottie；不自动绑定到日常构建。Mac 仅更新资源，未做本轮实机验收。

本机材料在 `work/brandMinimal20261024/`：改版前资源备份、原生渲染帧、预览与应用记录；首版材料保留在 `work/brandRefresh20261024/`。原生渲染核对入场不重播、不同等待时机收到就绪通知后完整退场、重复就绪不重启退场、最终透明帧；这不代替整个原生应用流程的验收。

Windows 同一数据目录只运行一个桌面实例：在启动动画、服务和窗口创建前绑定命名管道，重复启动只恢复并激活原窗口；加载中的唤起请求等首次页面就绪后合并执行。进程退出或异常终止后系统释放管道，不使用残留锁文件阻止下次启动。本轮并发与异常退出恢复记录在 `work/desktopInstance20261024/`；界面最小化与任务栏表现仍需实机交互核对。
