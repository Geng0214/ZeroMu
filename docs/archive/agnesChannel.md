## 配置与支持范围

在模型渠道中使用 OpenAI 格式，API 地址为 `https://apihub.agnes-ai.com`（也接受末尾 `/v1`），密钥通过现有设置界面保存。仅此官方网关和明确型号应用 Agnes 协议，不按渠道显示名称判断。

| 型号 | 已适配协议 | 真实验证 |
| --- | --- | --- |
| agnes-image-2.1-flash | 文生图、图片参考；1K/2K/3K/4K；一次一张 | 尚未执行 |
| agnes-image-2.5-flash | 文生图、图片参考；1K/2K/3K/4K；一次一张 | 1K 方图文生图及单张本地图片参考成功 |
| agnes-video-2.5 | 文生视频、公开地址的关键帧/参考协议；4–12 秒；720P/1080P/1K/2K | 第三十四批 4 秒 720P 提交返回预扣额度不足 HTTP 403，无 video_id；未生成视频 |
| agnes-video-2.5-flash | 文生视频、公开地址的关键帧/图片与音频参考协议；4–12 秒；仅 720P | 早期 4 秒内景、5 秒外景及第三十五批独立 4 秒空镜均返回 HTTP 503，无 video_id，保留待核对 |

图片模式需关闭“流式图片”和“Codex 兼容模式”。不支持的选项在发送前报错。默认尺寸为 1K；宽高比使用官方 `ratio`。参考图通过 `extra_body.image` 发送；本地图片由应用读取并转换为数据地址。文本生成和参考生成的 Base64 参数位置不同，适配器分别处理，不能直接套用通用网关参数。

视频提交使用 `mode`、字符串 `seconds` 和 `size`；查询使用实际 `video_id` 及同一 `model_name`。只有完成状态及有效结果地址同时出现才交付结果，早期地址不视为完成。已保存提交响应时，恢复只查询原任务。

**视频本地参考尚不可用。** 官方协议要求供应商可访问的媒体地址，当前应用的本地参考会转换为数据地址，尚未接通公开媒体托管或供应商上传。适配器在发送前拒绝这类引用；表中的公开地址协议验证来自注入响应检查，不代表工作站上传路径已经打通。不将本机预览地址当作公开地址，也不自动发布用户素材。独立音频生成渠道尚未确认。

协议来源：[Image 2.5 Flash](https://agnes-ai.com/en/docs/agnes-image-25-flash)、[Video 2.5](https://agnes-ai.com/en/docs/agnes-video-25)、[Video 2.5 Flash](https://agnes-ai.com/en/docs/agnes-video-25-flash)。实际账号权限和可用目录仍需分别核对。
