本机媒体工具复用已有 FFmpeg/ffprobe 6.1.1 essentials，实际状态接口执行成功。工具版本、二进制摘要见 sampleFfmpegSetup.json。没有在本轮重新下载工具，也不将本机已有 WebView2 当作缺失运行时验证。

## 指标口径

| 指标 | 计算与记录方式 |
| --- | --- |
| 首次独立完成率 | 5–8 名目标试用者逐人记录是否独立完成生成并保存，再算比例；本机自动化不计试用者 |
| 主动操作时间 | 有效凭据后至提交的实际操作时长；排队、生成、下载、返工等待分别记录 |
| 可追踪率 | 实际已发起请求中有稳定持久任务与输入快照的数量/全部已发起数量；保留失败尝试 |
| 恢复覆盖 | 按提交、轮询、下载、登记、保存阶段逐个记结果；“明确待核对”和“恢复成功”分别列示 |
| 采用率 | 实际采用的候选数/全部生成候选数，按媒体、模型和范例分组；不拿成功率替代质量 |
| 采用镜头成本 | 与采用前全部尝试相关的已核实支出/采用镜头数；估计和未核对部分另列，不跨币种直接相加 |
| 修改耗时 | 从提出修改到重新采用，分别记主动操作与供应商等待；保留原候选、选区和新依据 |
| 首开与交互 | 使用实际就绪标志或明确的画面可见边界；工具调用往返时间只能标为观察上界，不能称 INP、帧延迟或模型延迟 |
| 长任务 | 有逐条浏览器性能记录时报告超过 50 ms 的任务和归因；累计脚本/布局时间不能证明某一条长任务 |
| 内存 | 服务 RSS、渲染器 JS 堆、GPU/Blob 范围分别说明；不同 GC 时刻的两次值不直接算稳定优化率 |
| 包与导出 | 记录输入字节、任务创建/完成时刻、取消时实际写入字节、原件摘要与独立恢复结果；轮询间隔需说明 |

## 导航职责

画布仓库的“打开项目”选择已有目录，载入该目录已有画布；“导入画布”读取画布文件；“新建画布”创建新工作面。主菜单负责回到主页和画布仓库，画布下拉只切换当前目录内画布。导演台保留布景与机位任务，任务中心负责生成进度、原任务恢复和返回原位置，分镜面板负责制作顺序及采用。

第二十六批实际补齐了画布仓库打开项目的缺口，检查取消、键盘 Enter、窄窗口和三个既有项目切换，没有新增多余画布。原生目录选择器、系统 DPI、跨设备与目标用户可理解性仍按 F12/M5 验收，不能用浏览器目录选择器替代。
