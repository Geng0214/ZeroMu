日期：2026-10-20，第四十七批。对应 [产品计划](productDevelopmentPlan.md) 中供应商执行边界，承接 [工具隔离](pluginExecutionIsolation.md) 和 [项目包恢复](studioHistoryPackage.md)。

## 实现范围

媒体供应商的模块加载、元数据求值及生成闭包移入独立 Bun 工作进程。宿主只读取静态元数据、管理明确能力，并接收结果快照，不再直接执行供应商闭包。每个实例固定源码和当前供应商配置，环境不继承应用数据目录或其他配置；普通用户子进程仍以当前账户运行，不代表操作系统权限沙箱。

初始化限时 5 秒，模块初始化保留原时限。生成过程支持长时间等待；合作取消传递到实例，不响应取消的实例会被终止。已开始的保存和回执处理结束后再释放生命周期。检查、调试和持久媒体生成的调用方均在 finally 释放实例，不自动重新执行生成。

实际请求仍经宿主凭据传输检查；工作区授权、FFmpeg 输出业务保护、系统配音、固定背景移除、任务回执和结果保存继续由宿主掌握。供应商请求和响应通过明确数据与流接口传递，保留 UTF-8、二进制、响应克隆、逐项结果和用量回执。原生 FFmpeg 工厂在工作进程重建，流和事件在本进程运行，输出保护回调宿主。模型渠道使用宿主固定的当前配置，不接受供应商替换业务上下文。

供应商调试的预览读取另修正为先克隆再访问流；在当前 Bun 下，原先顺序会令后续流读取为空，而原生 text 方法仍能读取。修正后调试预览和实际结果均保持，正文仍可显示并脱敏。
