# 成片面板的字号、窗口与键盘操作

日期：2026-10-20，第五十批。对应 [产品计划](productDevelopmentPlan.md) 的首次使用、键盘与窗口门槛，沿用 [固定设备与窗口口径](acceptanceBaseline.md)。

## 修改与实际范围

应用字号原来上限为 125%，计划中的 150% 无法选择。现在设置与读取范围统一为 85%–150%，原有默认值保持。内置浏览器通过 End 键实际选择 150%；测得 100% / 125% / 150% 的根字号分别为 16 / 20 / 24 px，正文为 14 / 17.5 / 21 px。

制作导航固定在滚动区顶部，反向键盘遍历时曾完全盖住输入框或按钮。公共制作面板现在按实际导航与控件边界显示焦点；页签在窄窗中按完整词组换行，抽屉保留开合过渡，窗口尺寸变化直接采用新宽度。

成片保存和导出按钮进入加载状态会失焦。键盘保存完成后恢复到保存按钮；导出请求受理后进入成片记录，可继续 Tab 到新结果的预览。关闭面板、切换目录或用户已移动焦点时保留用户的位置。该处理在两项操作间复用。

变更文件为 apps/web/src/stores/settings.ts、components/settings/panels/ui.vue、pages/workspace/components/productionPanel.vue 和 filmPanel.vue，未增加依赖、测试文件、临时检查脚本或自动检查入口。
