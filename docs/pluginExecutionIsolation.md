# 工具执行的独立进程实现与验证

2026-10-20，始于执行记录第四十二批。源码中的 Agent、MCP 和团队私有工具通过独立 Bun 进程加载插件、校验配置、创建工具并执行插件闭包；宿主继续执行受信任的 SDK 构造器及文件队列、工作区授权和持久媒体任务。下文保留第四十二批源码、编译接口及仓库外冷运行的历史范围。第四十三批已补齐防御性加固、实际 2.0.13 安装、隔离工具与原生宿主联合验收及正常重开，见 [安装版记录](windowsToolBoundaryIntegration.md)；工作画布字节变化例外也在该记录中保留。

## 执行与生命周期

`loadTool` 读取既有工具格式的源码快照后交给 `createIsolatedTool`，不再在宿主动态 import 插件。每个实例有独立引用表和调用范围；环境仅继承运行必需项，不传应用数据目录或环境哨兵。不同项目和源码快照的实例互不共用引用。

主通道使用 Bun IPC。函数和原型对象使用显式引用，Buffer、循环数据及 Error 保留相应数据；属性的可枚举状态也保留，避免把 Zod JSON Schema 的隐藏 `~standard` 校验函数加入公开目录。引用不能通过 constructor、prototype 或 __proto__ 继续取得宿主原型构造入口。

SDK 构造器、技能目录和对象方法等同步调用，通过实例专用的 127.0.0.1 随机令牌接口及短期同步客户端返回。该接口拒绝携带 Origin 的请求，不注册到应用公开路由；长期 Promise 返回票据后继续经原 IPC 等待。实际文件、提问、画布、技能和媒体能力仍由宿主处理。第五个 Agent 上下文延迟读取，不提前遍历会话、模型注册表等对象；MCP 不提供的能力仍明确拒绝。

初始化、配置校验与创建定义各有 5 秒截止。执行不设置固定墙钟时限，以保留用户答复、媒体任务及 FFmpeg 等长操作；AbortSignal 转发后，插件若两秒仍不结束，则终止该实例。进程退出、断开和取消不自动重试原执行。已结束范围的延迟文件回调被拒绝；已进入宿主的文件操作等待结束后再释放待处理 SDK 回调，避免提前放开文件编辑队列。

Agent 运行结束释放工具集；MCP 目录先保留参数与说明，再释放用于枚举的实例，每次实际调用也在 finally 释放。团队释放其私有插件；本地委派不释放继承的父工具。A2A 保留等待补充输入的上下文，在完成、失败、取消和配置中止时释放；本批未调用真实团队模型任务，A2A 多轮模型验收继续保留。

## FFmpeg

宿主确认可用程序和工作区业务保护后，向插件传递原生工厂的描述。插件进程重建相同的 `createFfmpeg` 工厂，Readable、Writable、背压、链式调用、clone、preset 回调及事件均在插件内运行，输出业务保护仍同步回调宿主。没有将原生流接口缩减为 JSON 命令。

运行命令关联取消信号；正常退出时结束已登记命令。Windows 在插件仍存活时使用该插件 PID 结束进程树，再结束插件。实测不响应取消的插件及其 FFmpeg 均已消失，另一个项目仍可执行。此项不等于操作系统沙箱，也不宣称已经验证所有硬崩溃、恶意派生进程或其他操作系统的进程树清理。

## 发现与修正

- 初次 SDK 内联调用遗漏第二个旧式 edit 参数的 prepare；按实际 SDK 调用流程准备双方参数后通过，没有修改产品参数兼容逻辑。
- 初次定义循环调用误传空上下文，未进入插件；使用实际 ToolContext 后通过。异常源码仅在内存调用，没有写出合成工具或测试脚本文件。
- 传输曾把隐藏属性改成可枚举，导致 Zod 的 `~standard` 函数进入 MCP 目录并在清理后失效；保留可枚举状态后，源码和编译/冷目录均通过。
- 团队清理后曾捕获 undefined 取消原因；现在保留明确的关闭错误，并在入口先拒绝已释放实例。没有将尚未证实的原因归为 Bun 缺陷。
- 初次 HTTP 观察未附设置接口要求的来源/工作区头，关闭设置也遗漏 base；原失败记录保留，后续补齐实际契约，没有放宽来源保护。
- 五类 MCP 工具通过后，独立目录的 system 模式未发现运行时注入 PATH 的 FFmpeg。改用该隔离目录中的真实程序及 auto 模式后，FFprobe 返回 16000 Hz / 0.2 秒。另一次断言误把已解析的数值当作字符串，修正观察后通过，没有更改产品探测逻辑。`compiledHttpMcpVerified.json` 为最终补齐记录，不把前两个失败命令改写为成功。
- 外部 Bun 1.3.14 驱动与 1.4.0 宿主的 advanced IPC 首次无法互解；仅外部启动控制改用 JSON。产品宿主与工具工作进程均使用同一 Bun 1.4.0，保留 advanced 协议并通过真实调用。

## 尚未完成

插件自定义同步 prepareArguments、renderCall 和 renderResult 暂不支持；创建时明确返回 400 / TOOL_SYNC_HOOK_UNSUPPORTED，不会静默丢弃或回到宿主执行插件。SDK 内置同步钩子正常保留。第四十三批已完成实际新安装包、重开及真实画布读取回调；自定义钩子兼容、真实 Agent/团队及 A2A 等待输入、真实提问和持久媒体故障联合验收仍需继续。普通用户子进程保留当前用户的文件和网络权限，不是恶意代码沙箱；供应商 VM 和浏览器节点/工具界面也是单独边界。

本批没有新增依赖、测试文件、框架、临时检查脚本、付费生成、本机配音或背景推理。主配置摘要保持 `65bb7d1f460553d78bba7de21ff633dace367b001a74c339d0e5c4901205a84a`，锁文件摘要保持 `474e04643071c40f553d92ae4e71566fdd1a21f1235e29195bdc77e6f518bb0b`。Agnes 六次生成请求、估计占用 0.445 美元及人民币 10 元内部上限保持，实际账单未知；完整 M0–M5 与 P2 目标保持活动。

第四十七批另将媒体供应商模块加载及生成闭包移入独立工作进程，见 [供应商执行隔离](providerExecutionIsolation.md)。本文件的工具执行与第四十二批历史结果保持原范围；供应商不再沿用宿主 VM 执行，浏览器界面、自定义同步钩子和操作系统权限边界仍未全部完成。
