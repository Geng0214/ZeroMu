# 零幕工作台设计记录
## Overview

路由为 `/studio/image`、`/studio/video` 与 `/studio/audio`，参考用户指定的 Infinite Canvas 两栏暗色工作台，服务于持续编辑参数、生成和查看结果的操作流程。
本文件描述工作台扩展及本轮跨页面响应式修订；首页既有视觉规范仍由 `docs/homeDesign.md` 与 `.impeccable/design.json` 维护。本次不改写二者。
实现依据：`apps/web/src/pages/studio/index.vue`、`apps/web/src/pages/studio/useStudio.ts`。
## Colors

暗色使用上述实际 CSS tokens：背景、面板、字段逐层区分，浅薄荷色用于焦点和选中反馈，暖红色用于错误。
已有亮色切换按同顺序覆盖为 `#f2f2ef`、`#fff`、`#f5f5f2`、`#e6e7e1`、`#c7c9c1`、`#232620`、`#5b6057`、`#275d45`、`#9d3324`。
## Typography

沿用应用字体；页面正文 13px，参数标签多为 12–13px，辅助信息 11px。工作台标题 22px/650，结果标题 20px；提示词行高 1.65。
## Layout

用户在紧凑栏基础上授权重新设计按钮格式与位置。按“填写提示词、添加参考、调整参数、执行创作”组织操作，保留现有深色视觉。默认底部布局，结果占主体；同一创作栏可切到侧边，侧边按窄栏重排。

桌面顶部导航高 56px。底部创作栏最大宽 1180px、内边距 14px 16px，在结果下方占独立网格行，最大高 56dvh；参数区内部滚动。提示词独占首排，高 64px；下方为上传参考、粘贴参考、素材库、提示词库，以及粘贴文字、清空和带文字的“切到侧边／切到底部”。常规参数宽 88px，输入控件与主按钮高 36px。主按钮使用既有浅薄荷色强调。

用户要求移除“更多设置”及隐藏参数面板。参考素材预览与移除直接显示在提示词下方；视频提供参考类型选择，上传、粘贴与素材库共用选定类型。图片宽高、模型尺寸和对齐直接显示，视频生成模式与可选声音按模型能力显示，音频参数与能力提示直接显示。底部独立操作行显示保存目录和主按钮。侧边模式提示词高 128px，模型占满宽度，三个常用参数并排；长参数区可滚动。760px 以下结果与创作栏按上下顺序分配视口内空间，各自内部滚动。

### 随视口宽高适配（2026-10-06）

网站与桌面共用页面，以尽量在一屏内完成主要操作为目标。首页、创作台与资料库外壳使用 `height: 100dvh`、纵向 flex 和外层 `overflow: hidden`；中间内容通过 `flex: 1`、`min-height: 0` 与可收缩的网格行分配剩余高度。长列表、结果与正文在所属区域内滚动；首页内容区及资料库内容区仍保留 `overflow: auto`，作为内容超出可用高度时的滚动回退，不承诺任意极端视口都无需滚动。

首页轮播占剩余高度，内容网格首行至少 160px，轮播舞台最高 340px；纵向留白和输入高度随 `dvh` 调整，输入框范围为 48–88px。高度不超过 700px 时进一步缩小轮播文案和输入区间距；宽度不超过 640px 时轮播只显示当前卡片，输入操作换行，发送按钮为 44px。导航在宽度不超过 1150px 时换至第二行并可横向滚动。

创作台结果区与参数 `fieldset` 分别内部滚动，保存／生成页脚置于 `fieldset` 外并禁止收缩。侧边布局占满可用高度；桌面高度不超过 740px 时压缩间距，底部创作栏上限调整为 60dvh，提示词高 52px。宽度不超过 760px 时，两种布局均转为一列两行，结果行为 `minmax(120px, 1fr)`、创作行为 `minmax(0, 2fr)`；提示词高 64px，参数控件高 40px，页脚操作按钮高 44px。手机继续使用内部滚动，不恢复整页自然滚动规则。

提示词库与我的资产共用资料库外壳，内容最大宽 1360px，导航在宽度不超过 1100px 时换行并可横向滚动。提示词列表与详情正文分别内部滚动，详情底部操作保留在正文之外；宽度不超过 650px 时改为上下两行，分别为 `minmax(100px, 2fr)` 与 `minmax(180px, 3fr)`。项目列表和素材网格使用 `min-height: 0` 与 `overflow: auto`；搜索、筛选和目录位于列表之外。项目在宽度不超过 600px 时单列，素材在宽度不超过 650px 时两列。

## Elevation & Depth

以明度分层和细边框组织信息，创作栏使用柔和阴影。保存／生成页脚在桌面、侧边及手机布局中均作为参数滚动区之外的独立行，使用相对定位并禁止收缩，滚动参数时仍可执行操作。
## Shapes

主面板和结果卡片圆角 10px，常规输入框 6px；创作栏中的模型及参数控件圆角 8px，提示词框 10px，外框 18px。空结果区域使用虚线边框。
## Components

可选模型列表只返回已保存非空 API Key 的渠道；预装供应商目录不视为已接入，未配置时禁用模型选择并提供“配置 API”入口。凭据存在不代表连通性已验证。选择渠道模型，填写或粘贴提示词，按模型能力调整参数；参考素材支持上传、剪贴板与素材库，生成前写入项目的 `studioReferences`。生图提供八种基础比例、2K／4K 预设与自动尺寸、质量、1–10 张数量，数量通过 `n` 传入生成链路，模型可声明受支持的比例。视频使用已有模式、时长、分辨率与声音选项。音频创作台提供参考音频、音色、格式与语速；通用音频渠道实际为语音合成，音乐生成和参考音频能力取决于模型适配器，界面明确提示。
按用户要求移除接口模式选择：生图、视频、音频工作台分别固定传递 image、video、audio，由后端调用对应渠道的 generateImage、generateVideo、generateAudio。无需手动选择接口类型。创作栏仅展示已配置的真实模型；缺少渠道时模型位置提供“配置 API”按钮。

主按钮按前置条件显示下一步：未配置模型时打开 API 配置，未选择模型时提示选择，缺少保存位置时直接调用目录选择器，条件齐备后显示生成图片／视频／音频。空提示词与历史读取错误阻止生成；运行中保留可操作的取消等待按钮。清空提示词为空时禁用，布局切换保留草稿。

生成结果按媒体类型展示图片预览、原生视频或音频播放器，以及提示词、模型和时间，支持下载与选择移除；历史分别保存在项目目录的 `studioImageHistory.json`、`studioVideoHistory.json`、`studioAudioHistory.json`，重新进入恢复结果。移除只更新记录，保留原文件。

## Do's and Don'ts

以最新按钮重排为准，侧边与底部复用同一组件结构；常用素材操作带文字，主按钮给出可执行的下一步，保留失败提示；模型不支持的能力不伪装为已生效。新文件与自有示例类名使用小驼峰，工作台局部规范不覆盖首页规范。

## 模型渠道弹窗

按用户提供的第二张参考图，模型渠道使用最大宽 960px 的居中深色弹窗，标题为“配置与用户偏好”。渠道视图隐藏设置侧栏，可通过左下角“其他设置”返回原设置导航；右下角“完成”关闭弹窗。编辑沿用既有自动保存行为。

渠道行包含名称、API 格式、API 地址、掩码密钥、选择和删除操作。点击“选择”后为每个模型指定生图、视频或音频用途；同一渠道可混合保存多种用途，默认模型按模型用途过滤。次行显示保存数量及支持的用途；OpenAI 渠道按已选模型显示 Base64／视频地址设置。渠道与默认模型之间保留紧凑的“模型列表”汇总栏，显示持久化模型总数并提供“拉取全部渠道”。批量拉取按渠道显示结果，成功后进入模型选择与用途配置；单个失败不影响其他渠道，不自动覆盖已保存模型。模型也可通过各渠道的“选择”入口管理；四类默认模型桌面并排、手机两列。系统提示词保持现有保存逻辑。未新增没有适配器支持的流式传输或 Codex 兼容开关。

## 旧模型清理

移除 TF-Router 预置模型、自动安装与自动登录配置入口。插件市场密钥独立保存，不再创建模型供应商。启动不预装媒体供应商；默认模型与创作选择器只列出已配置密钥的供应商模型。用户本地原有预装目录已备份移出活动 providers 目录。

## 音频创作与画布

“音乐创作”统一命名为“音频创作”。与语音生成节点共用音频渠道和默认音频模型。输入区可在所选项目中新建语音创作画布，保留文本、模型、音色、语速、格式；结果卡可将原音频文件引用与生成时的参数送入语音节点。旧历史缺少生成参数时不猜测当时的模型，节点使用默认配置。每次发送写入新的画布文件，不覆盖已有画布。尚未生成的参考音频不能直接转为文字朗读节点，界面提示先生成结果。


## 创作台布局优化（2026-10-05）

三种创作台共用紧凑布局：底部输入区最大宽 1180px，桌面提示词 64px 高，参数与图片宽高/对齐设置同排自动换行；模型刷新和渠道管理紧邻模型标签，保留文字提示与无 API 配置入口。侧边模式继续使用三列简易参数，生成操作停靠侧栏底部。

结果区域优先占据剩余高度，空态只保留一个媒体图标及操作引导。音频使用独立紧凑播放器卡片，显示提示词、来源、时间和画布/下载操作。此轮曾采用短屏页面滚动及 760px 以下取消内部高度裁剪的规则；该规则已由 2026-10-06 的视口内分区滚动替代，当前行为见 Layout。无结果时隐藏无可用操作的全选/移除按钮。

实际验证覆盖 1440×900 底部生图与音频、1024×768 侧边、390×844 视频布局；无横向溢出。本地音频卡约 225px 高，播放器和操作区完整可见，播放器加载无错误。未调用外部生成 API。


## 渠道 API 格式（2026-10-05）

API 格式取代渠道用途下拉，保留原地址和密钥。可用格式为 OpenAI（生图、视频、音频）、APIMart（生图、视频）、MiniMax & METASO（当前适配视频）；Gemini、Grok2API、88API、RunningHub 和 ComfyUI 显示“未接入”并禁用，避免把未适配的请求当作 OpenAI 发送。APIMart 与 MiniMax 复用项目现有适配器，使用渠道填写的地址。

模型用途在“选择模型与用途”弹窗逐项设置；修改用途或移除模型会清理该模型不再适用的默认选择。旧数据的渠道 kind 字段作为兼容回退，保存后写入每个模型的 type；空渠道允许保存。没有恢复任何预置模型或自动安装流程。

隔离配置验证已覆盖混合用途保存读取、旧 audio 渠道迁移、不支持的格式/用途拒绝、清空模型，以及本地模拟 HTTP 的 OpenAI/APIMart/MiniMax 请求分发。页面验证模型用途选择后取消草稿，未修改真实 Agnes 配置，未请求真实外部渠道。

模型列表汇总栏补回验证：web 类型检查与构建通过，浏览器确认位置与数量。实际点击批量拉取时 Agnes 渠道连接超时，界面正确显示该渠道失败原因；本次未验证真实渠道成功返回后的选择流程，未改动已保存模型。截图：.impeccable/review/channelModelList.jpg。

默认模型衔接修复：批量和单渠道拉取结果直接进入默认模型候选组，选中时按用户指定用途保存，再设置默认值。不根据模型名称猜测能力；已分类模型只显示在对应类别。OpenAI 渠道支持文本用途，保存时同步现有 customProviders 文本运行配置。模型选择窗口点击保存会包含已勾选结果，移除时同步取消勾选。独立数据目录 defaultModelsReview 与本地模拟渠道验证了拉取、四类选择、持久化、刷新保留，以及 /api/ai/models 文本模型返回；未修改真实用户配置。web/server 类型检查、web 构建通过。截图 .impeccable/review/defaultModelsSaved.jpg 使用明确命名的本地验证模型。

模型分类根因修复：批量/手动加入不再使用 supportedKinds[0]。优先使用接口明确输出类型；缺省时保守识别 image/video/tts/speech 标记以及 Agnes 数字版 Flash/Pro 文本系列，未知模型保持待分类并阻止保存，不能出现在默认模型候选里。用途可由用户在选择窗口调整；已保存的显式用途不自动覆盖。本次通过窗口修复实际 Agnes 的 12 个错误分类：3 生图、3 视频、6 文本，未修改密钥/地址/已有节点。独立本地模拟返回同一批无类型模型，验证全选保存分类为 3/3/6，并验证 unknown-model 阻止保存。web/server 类型检查、web 构建通过。真实页面刷新后下拉验证通过，截图 .impeccable/review/modelKindsFixed.jpg。Agnes 文本输出参考官方模型卡 https://huggingface.co/Agnes-AI/Agnes-2.5-Pro-Alpha 。此规则取代此前未分类候选放入所有默认用途的实现。
