# 零幕 Windows 桌面版完善计划

更新日期：2026 年 10 月 20 日；基础检查始于 2026 年 10 月 9 日。

当前目标是把零幕完善为可安装、可持续更新、以本地项目为中心的 Windows 桌面创作工具。保留无限画布、生图、视频、音频、提示词和资产管理；官方模型中转、账号充值、会员和团队云服务移到后续商业化阶段。

## 产品决策

- 优先 Windows x64，继续使用 Vue、Bun 和 Electrobun；不为打包重写技术栈。
- 先保证已有创作流程、数据保存和升级可靠，再增加新能力。
- 保留深色与薄荷绿视觉系统，同时验证浅色、窗口缩小、键盘操作和系统缩放。
- 生图、视频、音频固定使用左侧创作面板，可拖动分界线，保留必要参数，不恢复底部栏切换。
- 不要求登录即可管理本地项目；模型渠道由用户配置。未配置模型时保留输入并给出明确入口。
- 本地后端只服务本机。未来公网模型服务独立建设，不复用桌面文件管理接口作为公网后台。
- 第三方插件、工具和模型供应商代码属于显式安装的可信代码，不宣称已经被沙箱隔离。

## 发布阶段

1. 开发验收：修复确定的问题，完成隔离接口验证、界面检查和 Windows 构建。
2. 内测安装包：真实安装、启动、关闭、重开；记录 Windows 版本和 WebView2 环境；验证旧项目读取和更新恢复。
3. 正式发行准备：配置自己的 HTTPS 更新源与发布身份，接入发布签名，完成干净 Windows 环境的升级演练。
4. 小范围内测：邀请真实创作者完成从输入到导出的工作流，依据问题优先修复，不以新增栏目数量衡量完成度。
5. 后续商业化：再建设独立模型服务、账号、订单、账本、支付和运营后台。

## 桌面身份与旧项目

零幕使用独立应用标识 `local.zeromu.desktop` 和启动协议 `zeromu://`，更新清单、原生更新辅助程序、安装登记与协议启动器保持一致，避免覆盖已安装的 Toonflow。默认安装到用户目录，不要求管理员权限。

内部 `@toonflow/*` 包名和项目文件格式继续兼容。已有 Toonflow 安装、配置和项目不自动迁移或删除。首次使用零幕安装到独立目录，再打开已有项目；需要迁移配置时先备份双方数据。使用旧应用标识的定制包不能直接视为本版的可原位升级版本。

## 接下来按顺序推进

1. 在可操作原生窗口的 Windows 环境验收安装、启动、关闭、重开、卸载保留数据，以及 WebView2 缺失时的处理。
2. 第三十八批完成现有九组依赖告警的源码处理与路由、MCP、公式/图表回归；第三十九批完成 2.0.11 本机实装、安装目录自带 MCP、原生预览、正常重启与 363 份既有项目文件保持，见 `dependencyMaintenance.md`、`windowsDependencyIntegration.md`。其他设备与持续依赖审计仍需跟进。第四十批已将配置保存和启用时的插件加载/校验移到独立进程，第四十一批补齐 2.0.12 实装、原生配置保存与正常重启，见 `pluginConfigIsolation.md`、`windowsToolProcessIntegration.md`；继续完成 Agent/团队执行及其回调的进程隔离，契约见 `pluginExecutionBoundary.md`。模型与插件市场 API Key 的系统保护、迁移、响应脱敏和错误处理已于 2026-10-13 验收，见 `apiCredentialSecurity.md`；这些部分结果不代表完整插件隔离已完成。
3. 用真实授权渠道分别验证图片、视频、音频的生成、取消、失败恢复、下载和资产复用，记录实际成本。
4. 用两个不同版本完成更新、异常中断和回退演练，确认安装目录外的项目及 `data/` 未受影响。
5. 配置自己的 HTTPS 发布源和代码签名，验证干净 Windows 机器的安装体验后再公开内测。

上述原生界面、真实模型和发行条件没有被浏览器检查或构建结果替代。当前包为未签名的开发验收产物，尚未公开发布。

## 本轮边界

本轮推进当前仓库可实施和验证的桌面功能、界面、安全与构建工作。第三方付费模型成功率只能通过授权的真实渠道验证；正式代码签名证书、域名和公网更新源需要真实运营资源。未具备这些资源时保留明确的发行前条件，不把内测包表述为已完成正式签名或公开发布。
