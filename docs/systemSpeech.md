# Windows 系统配音与实际音频验收

日期：2026-10-20。对应产品计划 F01、F08、F11；执行记录第二十九批。

已接入 Windows 自带的 System.Speech 文本转语音。它使用服务所在 Windows 设备已安装且启用的音色，通过固定命令调用系统语音引擎，应用不发起云渠道 API 请求，也不需要应用内 API 地址或密钥。第三十批已整合并在实际安装版生成两条 MP3；当时 2.0.7 候选另完成原生音频保存、正常重开和项目包上传恢复，详见 [安装版与原生文件验收](windowsNativeFiles.md)。第三十二批实际更新至 2.0.8，既有配音文件摘要及两个音色保留，见 [后续安装版验收](windowsBackgroundFiles.md)。下列主体保留第二十九批的独立服务验收依据。

## 使用

1. 在「模型配置」中点击「启用本机配音」。非 Windows 或没有可用音色时显示具体错误，不写入不可用的供应商文件。
2. 打开「音频创作」，点击「刷新模型」，选择保存位置、Windows 系统语音和实际音色，输入旁白或对白。
3. 选择 MP3 或 WAV，使用正常语速 1。每次最多 4000 个字符；暂不提供克隆音色、音乐、情感或语速变化。
4. 生成结果进入统一任务和工作站历史。停用渠道只影响新生成，已有文件和播放保留。

音色来自运行服务的设备。另一台电脑需要重新核对可用音色；打开已有配音不需要原音色、模型渠道或凭据。系统音色通常需要用户按创作需求试听，本次没有作自然度、角色表演或商业发行质量评价。

## 保存失败和恢复

第三条任务开始合成、持久化未完成检查点后，在原本不存在的输出位置创建普通文件，实际触发 EEXIST 保存失败。此时合成检查点已完成，音频资产已经持久化，任务可继续取回。保留并移走阻塞文件，重启服务后，通过原界面的「继续查询／下载」操作完成保存。

恢复前后检查点摘要相同，文件摘要与已完成合成的字节一致，用量回执仍只有一份。没有重新合成。相关证据：`saveFailureObserved.json`、`recoveryBeforeRestart.json`、`recoveryAfterRestart.json`；阻塞文件保留为 `saveBlocker.txt`。

同编号同输入返回原任务，修改输入返回 409，原任务文件完整摘要不变。未知音色、FLAC 和非正常语速在能力预检拒绝；空文本在 HTTP 校验拒绝。超长文本在适配器创建合成检查点之前拒绝。宿主再次校验文本和音色，不把提示词插入 PowerShell 代码；它只作为 JSON 标准输入传递给固定脚本。

如果进程在合成检查点尚未完成时被终止，仍按统一任务规则显示不确定状态，不自动重新合成。本批没有把这种情况标为已恢复，也没有验证进行中取消。

## 实际发现和修正

- 零元估算的最大费用取值在相等时落到 undefined，导致 BigInt 累加失败。已为未登记实际金额提供 0n 默认值；实际 CNY 0 项目预算可接纳本机任务。最初失败发生在合成之前，原失败记录保留。
- VM 内抛出的 Error 与宿主 Error 属于不同运行环境。原包装器直接重抛同文错误，任务记录丢失具体信息。已转换成宿主错误并保留拒绝标记；最新超长文本记录显示明确缩短文本提示，检查点为零。
- 原项目包只归集画布等引用，没有归集仅保存在工作站历史中的结果。本次实际导入暴露三条音频遗漏。已增加图片、视频、音频三类工作站历史的格式、路径、媒体摘要及来源任务归集；本批实际验证范围为三条音频，未另做图片和视频历史迁移回归。
- 项目包的模型依赖提示改为核对实际可选模型，已启用本机渠道不再被错误提示需要配置密钥；停用后仍提示需要重新配置渠道。

修正前项目包与目录 `speechRecovered` 保留为遗漏证据，不能作为完整音频交付。修正后的包见指针 `packagePath`；独立导入至 `speechRecoveredComplete`，三条音频摘要、工作站历史一致，三份任务回执为只读历史且不能恢复执行。`audioPackageRecovery.json` 保存实际归集结果与逐文件核对。

另在独立自有副本中更改历史记录里的音频摘要，实际归集在写包前失败，显示“工作站结果文件摘要已改变”，原项目历史摘要保持。证据为 `historyHashMismatchRejected.json`；没有修改原音频来制造该条件。

## 费用和范围

本批成功本机合成 3 次；没有新增 Agnes 或其他付费渠道生成。隔离费用策略以明确来源登记 CNY 0 估算，用量只报告字符数，没有伪造供应商收费、完整账单或零元实付。Agnes 累计仍为原 4 次请求，两笔 HTTP 503 视频保持不确定状态与估算占用，人民币 10 元总上限保持。

Web、server、providers 类型检查、Web 构建与 diff 空白检查通过。没有新增依赖、路由、测试框架、测试文件或临时脚本文件。Web 构建仍有既有大分块提示。原生整合、其他设备、系统音色差异、完整示范片和实际云端音频账单仍未验收；M0–M5 和 P2 的完整目标继续执行。

系统 API 依据：[Microsoft SpeechSynthesizer](https://learn.microsoft.com/en-us/dotnet/api/system.speech.synthesis.speechsynthesizer?view=netframework-4.8.1)。
