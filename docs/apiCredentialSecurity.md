# API 凭据保护与验收

更新日期：2026-10-13。范围为 Windows 本地零幕的模型渠道、文本/媒体供应商及插件市场 Key；没有调用用户的真实收费 API。

## 已完成的保护

| 风险 | 当前实现 | 验收 |
| --- | --- | --- |
| settings.json 明文保存 API Key | `credentialStorage.ts` 用 AES-256-GCM 加密凭据字段；随机 256 位主密钥通过 Bun.secrets 存入系统凭据库，JSON 只存密文和标识。Windows 凭据管理器使用 DPAPI。 | Windows / Bun 1.3.14 原生凭据库往返、新进程解密、旧配置迁移通过。 |
| 每次读取设置都向浏览器回传 Key | 普通设置及渠道保存响应只返回 hasApiKey、apiKeyUnavailable 和不可逆的版本标记。输入框保存后清空；拉取模型由后端使用已保存 Key。 | 设置 GET/PUT、渠道 POST 和真实表单操作均确认不回传 Key。 |
| 空输入误清除、其他窗口覆盖 | 省略 apiKey 表示保留，空字符串表示主动清除；界面有独立清除操作。版本校验与现有设置合并共同处理并发。 | 改主题/渠道名保留 Key，替换、清除、重新输入通过；过期窗口返回 409。 |
| 改地址后误把旧 Key 发到新站点 | 修改地址或协议必须重新输入 Key。保存和模型拉取校验 HTTPS，仅 localhost、127.0.0.1、::1 允许 HTTP。 | 地址变更不带新 Key 返回 400，远程 HTTP 在发送前拒绝；旧 HTTP 配置仍可清除 Key。 |
| 鉴权重定向与上游错误回显 | 文本节点、Agent、媒体供应商通过 credentialFetch 发请求；渠道鉴权请求绑定原站点并禁止重定向。上游错误剔除当前 Key，错误正文限 64 KiB/5 秒，未完整读取时丢弃正文。插件市场代理只允许固定官方地址及已有操作。 | 本机上游收到正确凭据；跨站/重定向拒绝；错误正文脱敏及超限正文丢弃通过。 |
| 解密失败导致配置丢失 | 保留原密文，界面显示需要重新输入；凭据库失效时拒绝明文保存。 | 损坏密文仍可启动、HTTP 报告不可用，重新输入后恢复；凭据库故障模拟未回退明文。 |
| 旧浏览器缓存导出带出 Key | 缓存导出对常见凭据字段和嵌套 JSON 生成脱敏副本，不修改原缓存。 | 导出样本不含人工 Key，普通字段与原数据保留。 |

迁移仍使用 Conf 的原子配置提交：先完成加密再写入原文件，不创建明文备份。普通配置保存不再无条件重启 MCP，也不再使所有模型列表失效。

## 用户使用方式

1. 在模型渠道或供应商设置中输入 API 地址与 Key。保存成功后输入框会清空，并显示已保存状态。
2. 修改名称、模型或其他设置时，密钥框留空即可保留。需要替换时输入新 Key；需要删除时点击清除或勾选清除后保存。
3. 更换 API 地址/协议时必须重新输入 Key，避免把已有凭据交给新的服务。
4. 画布保存和导出以模型引用为主，不打包渠道配置或系统凭据库。保存 API 密钥应使用配置界面，不要把 Key 写入提示词、节点正文或供应商源码。
5. 备份 data 目录可保留配置密文；复制到其他 Windows 用户/电脑时可能无法解密，界面会要求重新输入 Key。请在服务商处妥善管理、撤销及重新签发凭据。

## 安全边界

- 这是本机凭据保护，不是绝对防护。运行时后端需要明文 Key；同一 Windows 用户下的恶意软件、管理员、内存转储及受信任插件仍可能访问凭据或代发请求。供应商源码和插件仍须来自可信来源，不能把 VM 当成完整安全沙箱。
- Bun 1.3.14 使用 Windows 用户范围的系统凭据库；域账户漫游配置可能让凭据随用户漫游，因此不承诺严格绑定一台设备。主密钥不与 JSON 并排存放，也不硬编码进程序。
- 旧版本浏览器缓存、历史备份、日志或用户自己写进文本/源码的 Key 不会因为本次迁移自动消失。缓存导出按字段脱敏，不能识别任意文本中的所有秘密。
- 本轮核查的是模型 API Key 和插件市场 Key；MCP/A2A 本机访问令牌、第三方插件的任意自定义鉴权字段属于各自协议与信任边界，不能由此宣称全部凭据已经隔离。
- 本地桌面 API 继续只面向本机，不可直接作为公开中转站。商业中转站应在独立服务器保存商户上游 Key，向客户端下发可撤销、可限额的用户令牌；用户、额度、计费账本、限流、审计和滥用控制需在服务端执行。不能将商户总 Key 放进安装包。
- 本轮未进行真实付费模型调用、Windows 安装器签名或跨版本更新验收。macOS/Linux 系统凭据库路径没有在这台 Windows 机器上验收；不存在明文降级方案。
