# 全局素材带入与原文件重新定位

## 带入项目

在“我的资产”的素材卡片、画布“资产库”的文件行，或“项目制作 → 素材版本”中选择“带入项目”。选择目标目录；目录还没有制作记录时，明确点击“在此目录建立制作记录”。

可以建立独立项目素材，也可以选择已有素材及父版本，保存为新版本。核对页显示来源、名称、类别、原文件大小、描述、分类、标签和内容摘要。确认时再次核对原件；预览后全局文件或资料变化时，拒绝使用过期输入。

带入保存项目内副本和固定版本，不依赖全局原位置持续可用。之后编辑、改名或删除全局原件，不改变已带入的版本。已有镜头、候选和采用继续使用原版本，更新镜头参考仍在“使用位置与更新范围”中选择范围。

原有画布直接拖入继续适用于轻任务副本；需要登记制作素材身份、版本和来源时，使用“带入项目”。此操作不自动添加生成节点、替换画布连接或请求模型。

单个文件最多 100 MB。支持保留图片、视频、音频、文字以及其他普通文件。文字原件不超过 100,000 字节时同时填入文字设定；较大文字保留完整固定文件并显示提示，不自动截断。

## 中断后继续

确认带入时，原输入和原文件保留在项目管理的待完成目录中。再次打开同一项目的带入弹窗，可展开“待完成的带入”，按目标名称、来源和短编号选择原输入，然后重新核对。

已保存完整原副本时，继续操作使用原副本，即使全局原件后来移动或编辑，也不会串用新内容。原副本尚未写入完整时，需要全局原件仍能通过原摘要核对。副本损坏或同编号输入不同会被拒绝，并保留原目录。不要通过普通文件接口改写这些管理记录。

相同编号与输入在响应丢失或重启后重试，只返回原固定版本，不重复加版本或制作修订。项目包包含已登记的固定文件和待完成带入副本；导入后仍可核对并继续。尚未复制完整的原件会在项目包中提示后续核对要求。

## 文件移动后补回

在“素材版本”中选择具体版本，点击“检查 / 重新定位文件”。检查会读取文件并核对摘要，区分正常、缺失、内容已变化和无法读取；只在主动检查时执行。

对缺失文件选择“选择原文件补回”，通过文件选择器选取移动后的原件，再点击“核对所选原文件”。只有字节摘要与原固定版本完全一致时，才显示“确认补回原文件”。确认后复制回项目记录的固定位置，保留所选原件，不创建新版本或更改镜头引用。

不同内容不能作为原件补回；固定位置已有不同文件或无法读取时不会覆盖。内容修改应保存为新的素材版本。记录在其他页面更新时，先重新检查再核对原件。

当前素材版本的预览在补回后重新读取。其他已经打开且读取失败的画布预览，可重新打开画布刷新；原采用关系和文件引用保持不变。

## 数据与验收范围

制作格式仍为 schemaVersion 1，增加可选的 libraryImports 和 fileRecoveries；旧项目无需迁移。来源快照、固定副本、带入回执和文件补回审计随制作记录保存，快照恢复保留后来新增的记录与版本。

本地验收使用隔离数据目录和文字、合成像素素材。它验证文件与引用行为，不代表真实模型生成质量、收费、系统缩放或正式安装包已经验收。具体证据见 productDevelopmentProgress.md 第十七批。
