# 渠道、凭据与费用

更新：2026-10-23。以下为项目已有适配与验收记录汇总，未在本次文档整理中重新查询供应商价格或可用性。

## 配置与能力

保存配置、拉取模型列表、连通检查和真实生成是不同状态。只对实际可用渠道显示相应生成入口，参数按已声明和适配的能力开放；模型出现在列表不代表账号有额度或可以成功生成。

已保存 Key 由本机后端保护，界面显示配置状态；替换、清除或改变请求地址需要明确操作。迁移电脑后重新输入凭据，不复制密文文件就宣称渠道可用。系统保护范围见 [技术边界](../architecture.md#凭据与本机服务)。

## Agnes 已有范围

记录中的网关为 `https://apihub.agnes-ai.com`，使用 OpenAI 格式，接受末尾 `/v1`。适配根据实际网关和明确型号判断，不根据渠道显示名称猜测。

| 型号/能力 | 适配与已有真实结果 |
| --- | --- |
| agnes-image-2.1-flash | 已有文生图/图片参考协议适配，尚无该型号真实生成验收 |
| agnes-image-2.5-flash | 1K 文生图及一张本地参考生成各成功一次 |
| agnes-video-2.5 | 一次 4 秒 720P 提交返回额度不足 403，无 video_id；未成功生成 |
| agnes-video-2.5-flash | 三次提交返回 503 且无 video_id，保留未知/待核对 |
| 独立云音频 | 尚未确认；Windows 本机配音不计作 Agnes 或云音频验收 |

图片使用时关闭“流式图片”和“Codex 兼容模式”；不支持参数应在发送前反馈。Agnes 视频本地参考尚未接通供应商可访问的上传/托管，当前会拒绝数据地址；公开 URL 协议适配不等于应用已实现本地视频参考上传。应用不自动公开用户素材。

型号支持参数、原始请求与历史官方依据保留在 [Agnes 专项记录](../archive/agnesChannel.md)。其中宣传价格及促销是当时材料，使用前需重新核对账号实际条件。

当前不新增外部付费生成。三笔未知视频没有供应商任务号，不能证明没有创建或扣费；保留原记录，先联系渠道核对，不清空占用后重做、不改号重发。恢复仅适用于已有可查询响应或已有结果；缺少恢复依据时明确拒绝。

停止等待不保证供应商停止生成或扣费。费用汇总区分估算、原始用量与人工核对账单，按币种分别展示；未知价格和未知提交也是不同状态。

## 已有本机能力

Windows 系统配音使用设备已安装音色，BiRefNet 背景移除在本机处理。已有文件可以随项目包恢复；换机器的新生成需重新配置环境。操作见 [创作说明](creation.md)。

这两类结果可以推进本地工作流，不替代真实云视频、云音频、供应商账单或最终作品质量验收。
