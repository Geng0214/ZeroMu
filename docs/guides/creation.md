# 创作与复用

[文档目录](../readme.md) · [渠道与费用](channels.md)。本页合并日常操作，功能完成范围见 [进度](../progress.md)。

## 开始与继续

1. 打开已有项目目录，或新建画布并选择保存位置。
2. 配置实际渠道和模型；没有模型也可先整理文字、参考和制作记录。
3. 在工作站、画布或 Agent 发起任务，在任务中心查进度、错误与原位置。
4. 查看候选后明确采用，再进入成片面板组织输出。

项目草稿保存正文、参数及参考。重新进入工作站沿用上次草稿目录，明确打开其他项目才切换；读取失败时保留原件并重试。旧版其他网页端口的缓存仍需从原来源取回，不承诺自动找回全部历史缓存。

## 素材与版本

在我的资产、画布资产库或项目素材版本中选择“带入项目”，核对目标、来源、名称及摘要，再创建独立素材或已有素材的新版本。项目内固定副本不因全局原件后来移动或修改而改变；普通直接拖入与登记固定版本是不同操作。

更新角色、场景或道具后，查看使用位置并选择要更新的镜头；旧候选、原采用与生成依据保留，不自动重新生成。带入中断可从同一项目的待完成记录继续，同编号相同输入不重复创建版本。

缺失固定文件时，在版本中选择“检查 / 重新定位文件”，选取原件并核对摘要。只有内容相同才能补回；不同内容保存为新版本，不能覆盖旧版冒充原件。详细限制见 [素材记录](../archive/assetReuse.md)。

## 候选与图片编辑

候选比较与采用分别操作；保留原图、父版本、参数和来源任务。本地裁剪、90° 倍数旋转与尺寸调整使用 FFmpeg/ffprobe，结果保存为新候选。模型生成的参考修改可能改变额外细节，不等同严格蒙版编辑。

## 画布图片拆分与镜头参数

选中一张已有图片，点击底部工具栏的剪刀按钮“拆分图片”。可选择四宫格、九宫格、横向三格、纵向三格，或自定义 1–8 行、1–8 列；至少拆为两张。“每格每边裁去”用于移除分镜边框，按原图像素计算。预览编号即新图片节点顺序，输出为独立 PNG，原图保留，新节点排在现有内容右侧并自动进入视野。一次撤销移除整批新增节点，重做可恢复其图片。

拆分在本地浏览器执行，不需要模型或 FFmpeg。原图限 100 MB，边长不超过 8192 像素，总像素不超过 3355 万；多帧图片取首帧。参数不合法或保存失败时显示错误，全部切片写入完成后才加入画布。切换画布或项目会取消尚未完成的拆分。

选中图片或视频节点，在下方创作面板点击“镜头参数”，开启“生成时加入镜头要求”。可选择环境交代、人物对话、情绪近景、角色登场、道具特写、俯拍布局六种预设，也可单独调整景别、视角、等效焦距与景深；视频另有固定、推进、拉远、跟随、摇镜与手持运镜。展开“查看附加提示词”可审阅实际描述。

镜头参数随节点保存和复制，关闭开关会保留参数。只有正常点击生成才提交模型请求，原始提示词不被回写，旧节点默认不启用；实际视觉效果取决于模型。这里创建的是画布图片节点，不会自动登记为制作面板中的分镜或候选。

## 提示词与制作模板

提示词库和制作模板库初始为空，由用户自行新增或导入；不再提供内置示例，也不会在启动或刷新时补回默认内容。已有个人内容保留。

| 对象 | 操作与边界 |
| --- | --- |
| 个人提示词 | 新增、编辑、收藏、标签与变量填充；导入先核对内容，独立保存 |
| 制作模板 | 定义输入、变量、流程、镜头结构和模型用途；应用前预览并映射到实际渠道 |
| 从制作单元提取 | 核对镜头数、采用与导出范围；结构和已完成单元可提取，但不能把结构草稿称为成品 |
| 独立应用 | 创建新画布、制作单元、镜头与固定版本，不覆盖原项目；应用本身不发媒体生成请求 |
| 中断继续 | 选择目标项目的待完成输入，核对冻结文件再继续；改输入则创建新的独立应用 |

模板导出可审阅文字、变量默认值、参考与模型提示，不携带应用凭据。普通正文中的私密内容仍需自行审阅；模板文件与包含媒体的完整项目包用途不同。具体字段/容量见 [提示词](../archive/promptLibrary.md)、[模板](../archive/productionTemplates.md)。

## 成片与项目交付

成片面板按已采用镜头排序，设置入出点、原声、旁白、音乐、字幕和输出规格，先预览再导出新 MP4。保存原素材与编辑清单；缺失片段、错误时长、音轨及空间问题先处理再导出。

完整项目包包含制作关系、画布、固定版本、实际媒体、工作站历史及可归集的任务依据。导入先校验清单、路径和摘要，再恢复到独立目录；已有不同内容不静默覆盖。目标机器需重新配置凭据、生成渠道及本机运行能力，已有成果可先查看。

本机已验证大包及无模型环境下查看已有媒体；另一台机器与完整真实作品仍待验收。原始专项见 [工作站历史恢复](../archive/studioHistoryPackage.md)、[原生大包恢复](../archive/windowsScaleRecovery.md)、[声音草稿](../archive/comicAudioProduction.md)。
