# 零幕导演台优化计划书

> 2026-10-13 补充验收：下文保留首轮实施记录。后续已完成姿态切换性能优化、机位键盘排序、焦距输入及完整 MP4 导出回归，最新结果与 API 凭据保护见 [导演台体验、交互性能与 API 密钥保护](directorAndApiPlan.md)。首轮中“未执行完整 MP4 录制”等限制不代表最新验收状态。

## 目标与设计决策

将现有 3D 导演台升级为可以直接布景、调整人物、保存机位并输出构图参考的工作台。用户无需先调用 AI，即可完成一次场景预演；原有 AI 场景、人物动画、运镜和视频导出继续保留。

参考 LibTV 的“轻量 3D 构图 → 多机位截图 → 发送到画布”流程，采用零幕自己的界面语言：中性灰、细分隔线、统一线性图标；选中状态使用明暗变化。三维画面是主体，避免彩色卡片和装饰性大标题。

## 对照分析

| 环节 | 现有问题 | 本次实施 |
| --- | --- | --- |
| 布景 | 人偶入口藏在设置里，基础物体需要 AI 创建 | 左侧添加人偶、立方体、球体、圆柱、平面与群众阵列 |
| 管理对象 | 缺少明确的对象列表和手动属性编辑 | 列表选择、搜索、重命名、复制、隐藏、删除；右侧编辑属性 |
| 调整人物 | 只能通过 AI 编辑姿势 | 姿态预设与关节旋转，保留已有骨架 |
| 控制视角 | 点击画面直接锁定鼠标，学习成本较高 | 默认鼠标环绕、滚轮拉近拉远；第一人称取景成为明确的模式 |
| 调整构图 | 缺少直观变换工具和标准视角 | 移动、旋转、缩放操纵器；正面、侧面、俯视、适配场景 |
| 保存机位 | 关键帧无名称，画幅依赖当前全局设置 | 保存命名机位与独立画幅；构图辅助线；直接截图发送画布 |
| 修改恢复 | 手动编辑没有撤销入口 | 场景编辑撤销、重做；保存成功后才提交，失败有恢复提示 |
| 使用小屏幕 | 两列布局拥挤 | 桌面三栏；窄屏保留画面并按场景、属性、AI 切换面板 |

## 实施清单与验收标准

- [x] **场景工作台**：左侧对象清单，中间画面、工具与机位，右侧属性 / AI；操作可通过名称或图标提示识别。
- [x] **手动布景**：添加基础模型及3×3 群众阵列；对象总量仍限制为 200。
- [x] **对象编辑**：点击模型或列表选中；操纵器与数值编辑同步；支持名称、颜色、位置、旋转、缩放、显隐、复制、删除。
- [x] **姿态控制**：站立、行走、坐姿、举手预设；可单独调整关节 XYZ 角度。
- [x] **视角与构图**：默认环绕操作；显式第一人称模式；标准视角、适配场景、画幅、焦距与三分构图线。
- [x] **机位与画布闭环**：保存机位名称、时间、比例；回看与重新排序；截图可直接发送图片节点，旧关键帧可兼容读取。
- [x] **可靠保存**：场景与动画一并撤销 / 重做；编辑基准位置时同步平移已有动画轨道，避免动画跳回旧站位；删除物体时清理对应轨道。
- [x] **稳定性与适配**：载入失败显示原因与重试；生成 / 导出期间禁止冲突的场景编辑；桌面与窄屏验证；保留资源释放与取消机制。
- [x] **交付验收**：类型检查、插件构建、真实浏览器操作、保存重开、截图输出；使用说明、完成记录与独立界面验收结论已更新。

## 本次边界

本次以现有安全的基础几何体和内置关节人偶为资产范围，不引入外部 3D 模型解析、全景图生成或额外付费服务。编组、多选、全景背景属于独立扩展，不作为本次验收项。所有展示出来的按钮均连接真实功能。

### 入口与操作

画布底部工具栏 → 更多节点 → 3D导演台 → 点击节点预览。左侧添加模型，中间调整视角，右侧编辑对象。点击“保存机位”保留构图，点击“截图到画布”直接输出图片。

在本次新建的“无限画布2”中保留了验收场景与导出图片，方便检查实际结果。场景是手动搭建的验收示例。

### 验证范围与限制

本次没有调用付费 AI，也没有重新执行完整 MP4 录制；保留原有生成和视频导出链路，动画数据调整已通过内联验证。场景历史上限 30 次，在节点挂载期间有效；重新载入节点或成功生成新 AI 方案后清空。机位排序仍沿用原有拖动实现。

### 设计继承核对

本次是既有导演台的功能与布局扩展，沿用运行中的项目主题与组件语言。设计核对依据如下：

- **主题与文字**：`apps/web/src/App.vue` 继续管理明暗模式、字体缩放和圆角；导演台使用 `--el-text-color-primary`、`--el-text-color-regular`、`--el-text-color-secondary`、`--el-bg-color`、`--el-fill-color` 与 `--el-fill-color-dark`。对象与属性输入使用 `font: inherit`，标题、表单与辅助文字沿用既有字体，以 15px、12px、11px 区分层级。
- **控件与状态**：`sceneEditor.vue` 复用 Element Plus 按钮、选择器、开关及对话框；导演台范围内的主色映射为主题前景色，选中对象与工具通过填充明暗区分。`sceneObjects.vue`、`objectInspector.vue` 与 `directorPanel.vue` 使用相同的主题 token、细边框和可见焦点；图标统一来自 `@tabler/icons-vue`。
- **布局与表面**：沿用 `apps/web/src/assets/main.scss` 的 `--ui-radius` 与滚动条主题。桌面为 210px / 自适应 / 290px 三栏，以 1px 分隔线组织场景、真实 3D 画面与属性 / AI。900px 以下切换为分面板与纵向滚动，机位和属性按顺序排列。
- **实际画面**：[桌面验收截图（1440×900）](../.impeccable/review/directorDesktop.png)与[窄屏验收截图（390×844）](../.impeccable/review/directorMobile.png)呈现上述规则；三维画面与操纵器承担工作内容，中性界面保留清晰的操作层级。
